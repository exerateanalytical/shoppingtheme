Three Approaches to Fix All 17 Issues

Same end result — different organization. Pick your preferred strategy.

★ Recommended — Approach A

Expand dark-platform.css to cover everything

One authoritative CSS file owns ALL color overrides for the navy platform. We add missing page scopes (.archive-layout, .search-layout, .page-checkout, etc.) and fix the source files that still emit conflicting dark tokens. Verified page-by-page as we go.

1. Fix critical CSS collisions in 4 templates
2. Expand dark-platform.css with 5 new page scopes
3. Fix mobile gaps in archive + search + product tabs
4. Fix button token inconsistency
5. Verify Lucide icons enqueue
6. Final visual pass all pages
  • ✓ Single file = single source of truth
  • ✓ Consistent with existing architecture
  • ✓ Easy to audit in future
  • ✗ dark-platform.css gets longer (~180 lines)
Approach B

Fix at the source — remove dark tokens from base CSS

Instead of overriding, change alluvia-base.css global defaults (p, h1-h6, form labels) to use CSS variables that resolve differently on navy vs light backgrounds. Requires adding new tokens like --color-body-text that inherit from context.

1. Add context-aware tokens to :root
2. Replace all hardcoded dark colors in base.css
3. Update every template to use new tokens
4. Test that light-bg pages (none currently) still work
  • ✓ Cleaner architecture long-term
  • ✓ No override cascade needed
  • ✗ High risk — touches every file
  • ✗ Since ALL pages are navy, no immediate benefit
Approach C

Template-by-template inline fix

Go into each template's <style> block and directly change dark color values to white/gold/teal. No new CSS file, no abstraction — just correct the wrong values in place.

1. Edit archive.php inline styles
2. Edit search.php inline styles
3. Edit page-product.php inline styles
4. Edit page-checkout.php, page-contact.php
5. Repeat for 6 more templates…
  • ✓ Simple, no abstraction
  • ✗ Color values scattered across 10+ files
  • ✗ Future color change = update everywhere
  • ✗ We've been here before — this is what caused the mess
